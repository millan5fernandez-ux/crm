# CRM personal · Demo

Versión de demostración de un panel personal (gastos, gym, comida, hábitos, calendario) con escena 3D isométrica.

- Todos los datos son ficticios y se generan al abrir la página.
- Lo que cambies se guarda solo en tu navegador (localStorage). No hay servidor ni cuenta.
- Botón «Restablecer demo» para volver a los datos de ejemplo.

Tecnología: HTML + CSS + JavaScript en un solo archivo, Three.js para la escena 3D.
