# CRM personal · Demo

Versión de demostración de un panel personal (gastos, gym, comida, hábitos, calendario) con escena 3D isométrica.

- Todos los datos son ficticios y siempre los mismos: el reloj de la demo está fijado en el viernes 30 de octubre de 2026, así que se ve igual pasen los días que pasen.
- Lo que cambies dura hasta que recargues la página. No hay servidor ni cuenta.
- Botón «Restablecer demo» para volver a los datos de ejemplo.

Tecnología: HTML + CSS + JavaScript en un solo archivo, Three.js para la escena 3D.
